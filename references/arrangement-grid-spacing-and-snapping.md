### 6.10 Using the Editing Grid

To make Arrangement editing smoother, the cursor latches onto grid lines standing for the meter subdivisions of the song tempo. That grid may be configured as either zoom-adaptive or fixed.

<a id="source-arrangement-view-part-2"></a>

To adjust how wide the grid lines are drawn — for both the zoom-adaptive and the fixed varieties — open the context menu found either in the Arrangement View track main lanes or within the MIDI Note Editor over in the [Clip View](https://www.ableton.com/en/live-manual/12/clip-view/#clip-view).

These keyboard shortcuts, mirrored as entries under the Options menu, let you reshape the grid in a hurry:

- Ctrl+1 (Win) / Cmd+1 (Mac) _narrows_ the grid, packing twice as many grid lines into the same space (say, shifting from eighth notes down to sixteenth notes).
- Ctrl+2 (Win) / Cmd+2 (Mac) _widens_ the grid, thinning the grid lines out to half their count (say, moving from eighth notes up to quarter notes).
- Ctrl+3 (Win) / Cmd+3 (Mac) toggles _triplets_ mode; as an example, that switches the grid from straight eighth notes over to eighth note triplets.
- Ctrl+4 (Win) / Cmd+4 (Mac) turns grid snapping on or off. With snapping disabled, the cursor stops locking onto meter subdivisions.
- Ctrl+5 (Win) / Cmd+5 (Mac) toggles fixed and adaptive grid modes.

Whatever distance currently separates one grid line from the next is shown just above the time ruler, over in the lower right corner of the Arrangement View.

Holding the Alt (Win) / Cmd (Mac) modifier as you carry out an action lets you sidestep grid snapping temporarily. And when snapping happens to be off, pressing that same modifier turns it back on for the moment.
