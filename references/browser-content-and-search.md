# Browser Content And Search

Open when you need guidance on Browser Content And Search in Ableton Live.

Context: [Working with the Browser](working-with-the-browser.md#4-working-with-the-browser).

<a id="source-41-content-pane"></a>
### 4.1 Content Pane

The Content Pane.

The content pane holds a list of the items belonging to a chosen label, or else the outcome of a search or filter. While the Name column stays on screen at all times, you can bring up extra columns by picking them from the _Content Options_ menu.

The Content Options Menu.

After choosing extra columns to appear, you may rearrange them by hand: click a column name and drag it where you want it.

To order the items in the content pane up or down by any column, click that column's name. Be aware that right-clicking a column name likewise brings up the Content Options menu.

Among the entries in the Content Options menu is a toggle for displaying or hiding the file extensions on browser items.

<a id="source-42-search-bar"></a>
### 4.2 Search Bar

Locate browser material by entering the term or terms you want into the search bar. What comes back are files matching _all_ of your terms rather than _any_ one of them. As an illustration, a search for “electric bass” surfaces only those items whose filenames carry both “electric” and “bass”.

If you want to look through every Library location, choose the All label, or hit Ctrl+F (Win) / Cmd+F (Mac), which jumps you to the All label automatically; that same shortcut drops a cursor into the search field too.

The Browser’s Search Field.

Tightening a search further is possible by picking tags out of the various [filter groups](https://www.ableton.com/en/live-manual/12/working-with-the-browser/#filter-groups) so the matches shrink. Say you are after string sounds: enter “strings” in the search field, then click whichever tags you like in the Filters view so that only results carrying those tag descriptions remain.

Searching by Term and Then Trimming the Matches with Tags.

Searching by [tags](https://www.ableton.com/en/live-manual/12/working-with-the-browser/#tags) is another route — type # in the search bar and follow it with a tag name, for instance #Drums. Once you begin typing past the hashtag, auto-complete proposals for tag names show up.

You Can Also Find Tagged Content by Searching For Tag Names.

The x button inside the search bar wipes whatever search terms you entered. Bear in mind this leaves the Filters view untouched. To strip out both chosen tags and typed search terms, reach for the Clear button on the Results bar.

Use the Clear Button to Remove All Selected Tags.

If you would rather search without the mouse, here is a keyboard sequence we recommend:

1. Ctrl+F (Win) / Cmd+F (Mac) to set a cursor inside the search field and move browser focus onto the All label;
2. Enter the terms or tag names you are searching for;
3. Down arrow key to move into the search results;
4. Up and down arrow keys to move through the search results;
5. Esc to empty the search field and bring back every item in the All label. Whatever tags were chosen get cleared too.
