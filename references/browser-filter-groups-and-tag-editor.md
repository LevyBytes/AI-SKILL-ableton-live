# Browser Filter Groups And Tag Editor

Open when you need guidance on Browser Filter Groups And Tag Editor in Ableton Live.

Context: [Filters and Tags](working-with-the-browser.md#44-filters-and-tags).

<a id="source-441-filter-groups"></a>
### 4.4.1 Filter Groups

Every filter group holds a batch of tags, and clicking them trims down what the content pane shows. For choosing more than one tag inside a single group, hold the Ctrl (Win) / Cmd (Mac) modifier as you click.

The Sounds Filter Group and its Associated Tags.

Which filter groups are on offer differs from one label to the next, and the on/off state of filters gets stored and brought back as you move among Library labels. As a result you can tailor exactly which groups each label displays however you need.

Bringing up further filter groups, or all of them along with their tags, is done from the Filter View menu.

You Can Choose Which Filters are Displayed for Each Label.

Right-clicking the name of a single filter group within the Filter View section also lets you conceal that group in a particular label. The _Reset Filter Groups to Default_ entry on the Filter View menu puts the label back to its default selection of shown filter groups.

How many filters are active at the moment is reported by the Results bar. Clicking its Clear button wipes the Filter View, dropping any chosen tags and search terms.

The filtered matches can be kept in a custom user label: just click the Add Label button that sits just past the Clear button.

<a id="source-442-tags"></a>
### 4.4.2 Tags

For rapidly finding or arranging your browser material, tags come in handy, all the more so once you make custom ones of your own. They are equally a fine route to stumbling onto material you have yet to meet — just pick a tag in the Filter View and browse the items tied to it.

Every piece of Live's factory material (that is, material from the Core Library and the Live Packs shipped with each Live edition) carries a batch of descriptive tags. Material from the third-party Packs sold in the Ableton webshop is tagged using the tags held inside the “Sounds” filter group.

The default tags on factory items cannot be stripped off; even so, you are free to attach other tags to those items and to add custom tags of your own with the Tag Editor.

From time to time Live carries out a [sound analysis](https://www.ableton.com/en/live-manual/12/live-concepts/#sound-similarity), and during that routine it tags user samples lasting up to 60 seconds. Whatever tag gets applied is the one the sound analysis judges to fit the sample's sound most closely.

The _Enable Auto Tags_ entry in the Filter View menu switches auto tags on or off, and within the Tag Editor they can be deleted or turned into user tags.

Live additionally tags VST3 plug-ins from their VST3 meta data whenever those plug-ins carry a VST Sub Category lining up with one of Live's categories.

<a id="source-443-tag-editor"></a>
### 4.4.3 Tag Editor

Building tags and attaching them to whatever items live in the browser is what the Tag Editor is for. On top of that, you can set up tag groups of your own to bring further order to your tags library.

Opening the Tag Editor is a matter of picking its dedicated entry from the Filter View menu.

Open the Tag Editor from the Filter View Menu.

After it opens, the tags presently attached to the chosen browser item are shown across the default filter groups.

The Tag Editor.

Clicking the arrow beside a group's name folds or unfolds that group. Whenever a folded group holds an assigned tag, its arrow gets a heavier background to signal this.

A Folded Group Containing Assigned Tags.

Attaching a tag to the chosen browser item, or pulling one off, is done by ticking or unticking the box beside the tag in question. Ticking several boxes lets you put many tags on the one item. If you want to tag a batch of items together, hold Shift, pick a number of files in the browser, and then apply the tags you want.

Custom tags can be slotted into any filter group through the _Add Tag…_ entry sitting at the foot of each group.

Use the Add Tag… Option to Create Custom Tags.

Likewise, groups of your own can be built with the _Add Group…_ entry down at the bottom of the Tag Editor.

Use the Add Group… Option to Create Custom Filter Groups.

After a new filter group exists you are free to add custom tags into it. The moment you attach one of the group's tags to a browser item, that group turns up in the Filter View and in the Filter View menu alike. It is a tidy way to arrange browser items around specific purposes — for example, gathering all your field recordings or vocal samples into their own dedicated groups so they are easy to reach afterward.

Rather than piling on several specialized groups, you may instead attach _subtags_ beneath a default or custom tag. Any tag carrying subtags is termed a _parent tag_. Folding and unfolding a parent tag is done by clicking the arrow next to its name.

Adding a subtag means right-clicking a tag and selecting the _Add Subtag in…_ entry. The freshly made tag then sits nested under the parent tag. Note that the tags in the Creator filter group cannot have subtags created for them.

You Can Add a Subtag to an Existing Tag.

Custom tags and filter groups can be renamed or deleted from their right-click context menus. Keep in mind that none of the default filter groups, nor the tags tied to them, can be edited or removed.

Shut the Tag Editor by hitting the X button in its top-right corner, or by choosing the matching entry on the Filter View menu.
