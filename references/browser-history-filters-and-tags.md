### 4.3 Browser History

Moving ahead or back through the browser's history is done with the arrow buttons sitting to the left of the search bar.

Use the Arrow Buttons to Access the Browser History.

The keyboard shortcuts below are available as well:

- Move ahead through the browser's history: Ctrl+] (Win) / Cmd+] (Mac)
- Move back through the browser's history: Ctrl+[ (Win) / Cmd+[ (Mac)

Both earlier searches and prior navigation states are part of the history.

### 4.4 Filters and Tags

A collection of filters comes with the browser, letting you search for particular material by way of descriptive tags.

The Browser’s Filter View.

Making up the Filter View section are _filter groups_ together with their attached _tags_. The section can be tucked away with the Show/Hide Filter View toggle, while the Filter View menu beside that toggle lets you decide which filter groups stay on screen.
