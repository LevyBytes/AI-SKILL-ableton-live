### 4.2.1 Saving Search Results as Custom Labels

When a given search turns up results you would like to return to easily down the line, build a custom user label holding those results by clicking the Add Label button positioned to the right of the Clear button.

Use the Add Label Button to Save Search Results.

After it is stored, the label and what it holds behave just like any other label in the Library.

A Saved Custom User Label.

Custom labels also let you gather particular items in a single spot for quick reach — much as the Collections labels do — by tagging material with tags of your own and then storing the search results as a fresh label.

Should a custom label you added earlier no longer serve a purpose, removing it is fast through its right-click context menu.

A label's context menu lets you rename labels of both the factory and custom kind. That same context menu also lets you pick a different icon for any label, giving you more room to tailor your browser.
