### 2.1 Installation and Authorization

Prior to diving into Live, confirm that the most current build is set up and authorized. Grab the Live installer from your ableton.com [User Account](https://www.ableton.com/account/), then run it to [install the software](https://help.ableton.com/hc/articles/209773565). With the install complete, proceed to [authorize Live](https://help.ableton.com/hc/articles/209773585). Keep in mind that every [Live license](https://www.ableton.com/en/eula/) grants two authorizations, letting you run the program across as many as two machines, as long as just one of them is active at any moment.

<a id="source-22-learning-about-live"></a>
### 2.2 Learning About Live

A range of resources exists both inside Live and beyond it, all aimed at helping you grow comfortable with the program and with making music more broadly.

Two learning aids ship inside Live itself: the [Learn View](https://www.ableton.com/en/live-manual/12/first-steps/#learn-view), which offers guided lessons, plus the [Info View](https://www.ableton.com/en/live-manual/12/first-steps/#info-view), which gives context-sensitive help. If you want to dig deeper, additional [resources available outside of the application](https://www.ableton.com/en/live-manual/12/first-steps/#other-learning-resources) exist too. Among them are this manual, video content, and interactive web apps.
