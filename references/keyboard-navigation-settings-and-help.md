# Keyboard Navigation Settings And Help

Open when you need guidance on Keyboard Navigation Settings And Help in Ableton Live.

Context: [Menu and Keyboard Navigation Settings](accessibility-and-keyboard-navigation.md#401-menu-and-keyboard-navigation-settings).

<a id="source-4011-using-tab-for-navigation"></a>
### 40.1.1 Using Tab for Navigation

Once the _Use Tab Key to Move Focus_ option has been turned on through the Navigate menu or by way of Live’s Display & Input Settings, you can rely on the Tab key for navigation in these manners:

- Tab moves to the next control.
- Shift+Tab moves to the previous control.

You may also employ the Tab key to step among controls within the Session and Arrangement mixers through the shortcuts below:

- Ctrl+Tab (Win) / Option+Tab (Mac) carries you onward to the following control within that same row.
- Ctrl+Shift+Tab (Win) / Option+Shift+Tab (Mac) carries you back to the preceding control within that same row.

With Use Tab Key to Move Focus disabled, a press of the Tab key toggles between Session and Arrangement View, the way it did in earlier Live releases.

Beyond moving focus with Tab, you also have access to these navigation choices:

- _Wrap Tab Navigation_ - With this turned on, once you reach the final control in an area, pressing Tab loops focus back to the very first control rather than halting. Should the first control be the active one, a press of Shift+Tab carries focus to the last control. Turn this on through the Navigate menu or via the Display & Input Settings.
- _Move Clips with Arrow Keys_ - Active by default, this lets the left and right arrow keys shift selected clips and/or the time selection inside Arrangement View. Disable the behavior in the Display & Input Settings whenever you prefer. With it off, the left arrow key shrinks the time selection down to its start point, whereas the right arrow key shrinks it down to its end point.

### 40.1.2 Settings Menu

Open Live’s Settings with the shortcut Ctrl+, (Win) / Cmd+, (Mac).

You can move between options within the Settings tabs by means of the Tab and Shift+Tab keys. Whether the [Use Tab Key to Move Focus](https://www.ableton.com/en/live-manual/12/accessibility-and-keyboard-navigation/#using-tab-for-navigation) option is on or off, these shortcuts still function.

While a command holds focus in one of the Settings tabs, the up and down arrow keys let you flip a toggle's state, tweak a value, or step through the choices offered for that command. The Enter key likewise lets you alternate between toggle states.

Move among the various tabs in the Settings Page Chooser with Ctrl+Tab (Win) / Option+Tab (Mac) and Ctrl+Shift+Tab (Win) / Option+Shift+Tab (Mac), or with the up and down arrow keys whenever the chooser holds focus. Should keyboard focus rest on the first control of any Settings tab, the Shift+Tab shortcut sends focus back to the Settings Page Chooser.

Shut the Settings window by pressing the Esc key.

Keep in mind that selecting a different preferred UI language in the Display & Input Settings requires a restart of Live before the change applies.

<a id="source-4013-options-menu"></a>
### 40.1.3 Options Menu

Additional accessibility settings live in Live’s Options menu, where you'll find an Accessibility sub-menu. Reach that sub-menu from the keyboard with Alt+O (Win) / VO+M then O with VoiceOver (Mac).

Within the sub-menu sit a handful of items that switch on particular screen reader announcements, namely Speak Menu Commands, then Speak Minimum and Maximum Slider Values, plus Speak Time in Seconds.

<a id="source-4014-speak-help-text"></a>
### 40.1.4 Speak Help Text

The majority of controls and regions in Live carry descriptive text, which you reach through the [Info View](https://www.ableton.com/en/live-manual/12/first-steps/#info-view). Under Windows, switch on screen reader announcements for those descriptions by turning on the Speak Help Text option inside your chosen screen reader. Under macOS, achieve the same result by enabling help text within the VoiceOver Utility’s verbosity settings. You may additionally reach this option by hand with a press of VO+Shift+H.
