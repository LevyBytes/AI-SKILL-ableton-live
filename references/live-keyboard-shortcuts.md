### 41.25 Momentary Latching Shortcuts

A number of shortcuts support momentary latching. In practice, this lets you press and hold the shortcut key to temporarily switch on its action; the moment you let go, Live’s interface snaps back to where it was. The latching behavior kicks in once you have held a shortcut key down for roughly 500 ms. These are the keys that allow momentary latching:

- A toggles Arrangement automation mode
- B toggles Draw Mode
- S toggles soloing the selected track
- Z toggles zooming into the Arrangement selection
- F1 through F8 flip the Track Activator switch for the first eight tracks between on and off
- Tab toggles between Arrangement and Session View

Should you want to disable it, momentary latching is switched off through the Options.txt entry: -DisableHotKeyLatching

### 41.26 General Keyboard Navigation and Workflow

The computer keyboard alone is enough to move through the majority of Live’s views, menus and controls.

Within Live’s menu bar, the Navigate menu gathers commands that shift keyboard focus across different parts of the UI, along with settings for moving between controls with Tab. You’ll find further navigation commands over in the Display & Input Settings.

### 41.26.1 Using Tab for Navigation

With the Use Tab to Move Focus option turned on, the Tab key supports navigation in these ways:

- Tab moves to the next control
- ShiftTab moves to the previous control

For moving among controls within the Session and Arrangement mixers, the Tab key works through these shortcuts as well:

- CtrlTab (Win) / OptionTab (Mac) advances to the next control sitting in that same row
- CtrlShiftTab (Win) / OptionShiftTab (Mac) steps back to the prior control sitting in that same row

With Use Tab to Move Focus disabled, a press of the Tab key flips between Session and Arrangement View, just as it did in earlier Live versions.

Beyond shifting focus with Tab, you also have access to these navigation options:

- _Wrap Tab Navigation_ - With this turned on, tabbing through a focused view won’t halt at its final control; instead it loops around to the first one. Likewise, when the first control is selected, ShiftTab jumps to the last. You can switch this on from the Navigate menu or within the Display & Input Settings.
- _Move Clips with Arrow Keys_ - On by default, this lets the left and right arrow keys shift selected clips and/or the time selection inside Arrangement View. If you prefer, it can be turned off in the Display & Input Settings. Once off, the left arrow key snaps the time selection down to its start point, and the right arrow key snaps it down to its end point.

### 41.26.2 Navigating Between Controls in the Settings Menu

To step through the options held within the Settings tabs, use the Tab and ShiftTab keys. They function here whether or not the Use Tab to Move Focus option happens to be active.

Whenever a command holds focus on one of the Settings tabs, the up and down arrow keys will flip a toggle’s state, tweak a value, or rotate through that command’s available choices. The Enter key can likewise be used to flip a toggle between its states.

Moving among the various tabs in the Settings Page Chooser is done with CtrlTab (Win) / OptionTab (Mac) and CtrlShiftTab (Win) / OptionShiftTab (Mac), or with the up and down arrow keys while the chooser has focus. Should keyboard focus rest on the first control of a Settings tab, pressing ShiftTab hands focus back to the Settings Page Chooser.

### 41.27 Editing Automation and Modulation Envelopes with the Keyboard

Breakpoints in automation and modulation envelopes can be added, modified, and removed straight from the computer keyboard. To read more on how this works, consult the [Editing Automation and Modulation Envelopes section](https://www.ableton.com/en/live-manual/12/accessibility-and-keyboard-navigation/#editing-automation-and-modulation-envelopes) found in the Accessibility and Keyboard Navigation chapter.

### 41.28 Accessing Menus

Under Windows, any menu opens when you press Alt together with that menu’s initial letter (AltF opens “File,” for example). With a menu showing, the following are available:

- The up and down arrow keys to step among the entries in the menu.
- The right and left arrow keys to jump open the adjacent menu.
- Enter to confirm a menu entry.

On Mac, pressing Cmd? reaches the individual menu entries. Doing so brings up a search field that offers menu entries as suggestions while you type. Move through those suggestions with the up and down arrow keys, then hit Enter to pick one.

### 41.29 Using Live’s Context Menu

Throughout various parts of Live, a context menu gives you fast access to frequently used actions and menu items. You bring it up by right-clicking (Win) / Ctrl-clicking (Mac) on whichever spot in the interface you want to act on. The menu can also be summoned with the Menu key or ShiftF10 under Windows, or VOShiftM on Mac. Keep in mind that this context menu will occasionally surface relevant options drawn from Live’s Settings. Adjust those with caution, since they reach beyond the item currently selected and touch the program’s overall settings as well.
