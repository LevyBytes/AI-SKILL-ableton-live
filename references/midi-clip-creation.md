# MIDI Clip Creation

Open when you need guidance on MIDI Clip Creation in Ableton Live.

Context: [Editing MIDI](editing-midi.md#10-editing-midi).

<a id="source-103-creating-a-midi-clip"></a>
### 10.3 Creating a MIDI Clip

There are several routes to making a MIDI clip:

- through [recording on a MIDI track](https://www.ableton.com/en/live-manual/12/recording-new-clips/#recording-new-clips);
- through [capturing MIDI](https://www.ableton.com/en/live-manual/12/recording-new-clips/#capturing-midi);
- by double-clicking a vacant Session slot on a MIDI track;
- by highlighting a vacant Session slot on a MIDI track and picking the Create menu’s Insert Empty MIDI Clip(s) command, which the Ctrl+Shift+M (Win) / Cmd+Shift+M (Mac) keyboard shortcut also triggers;
- by double-clicking the track display of a MIDI track over in the Arrangement View;
- or, within the Arrangement View, by highlighting a timespan on a MIDI track and picking the Create menu’s Insert Empty MIDI Clip(s) command, again reachable via the Ctrl+Shift+M (Win) / Cmd+Shift+M (Mac) keyboard shortcut.

<a id="source-104-adding-midi-notes"></a>
### 10.4 Adding MIDI Notes

MIDI clips gain notes as you record yourself performing an instrument on an armed track, or when you pull back the material you played through the Capture MIDI option. Notes can also be entered by hand in the MIDI Note Editor, either by double-clicking at a spot of your choosing or by drawing them with the mouse while Draw Mode is on.

The Control Bar’s Draw Mode Toggle.
