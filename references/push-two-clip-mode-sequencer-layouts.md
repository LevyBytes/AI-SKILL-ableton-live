# Push 2 Clip Mode Sequencer Layouts

Open when you need guidance on Push 2 Clip Mode Sequencer Layouts in Ableton Live.

Context: [Sequencing Layouts](push-two-mixing-automation-and-session-routes.md#35143-sequencing-layouts).

<a id="source-351431-melodic-sequencer"></a>
#### 35.14.3.1 Melodic Sequencer

Each page of the Melodic Sequencer layout spans a range of eight notes. You can shift the sequenceable area sideways with the loop length pads or the Page Left/Right buttons, and up or down with the Octave Up/Down buttons or the touch strip.

<a id="source-351432-melodic-sequencer--32-notes"></a>
#### 35.14.3.2 Melodic Sequencer + 32 Notes

Within this layout, the display rescales to bring every note in the clip into view. Selecting a note (or notes) already present in the clip highlights its sequenceable area on the display, which speeds up finding and editing the steps that hold those selected note(s). You move the sequenceable area sideways with the Page Left/Right buttons or the loop length pads, the latter reachable briefly in the fifth row while you hold the Layout button.

Loop Length Pads in the Melodic Sequencer + 32 Notes Layout.

Drums/Slicing Loop Selector and 16 Velocities

Only the chosen pad is displayed by the Loop Selector and 16 Velocities layouts. Move the sequenceable area sideways with the loop length pads or the Page Left/Right buttons, and up or down by picking a different pad.
