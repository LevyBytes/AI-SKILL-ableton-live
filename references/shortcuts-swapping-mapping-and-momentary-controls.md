### 41.23 Similar Sample Swapping

The shortcuts below apply within Drum Racks, individual Drum Rack pads, and Simpler.

|                                                               | Windows          | Mac             |
| ------------------------------------------------------------- | ---------------- | --------------- |

| Swap to Previous Similar Sample                               | Ctrl left arrow  | Cmd left arrow  |
| Save as Similarity Reference                                  | Ctrl up arrow    | Cmd up arrow    |
| Return to Reference                                           | Ctrl down arrow  | Cmd down arrow  |
| Temporarily Toggle Similar Sample Swap Controls in Drum Racks | Alt              | Option          |

### 41.24 Key/MIDI Map Mode and the Computer MIDI Keyboard

|                                                              | Windows      | Mac          |
| ------------------------------------------------------------ | ------------ | ------------ |
| Toggle MIDI Map Mode                                         | Ctrl+M        | Cmd+M         |
| Toggle Key Map Mode                                          | Ctrl+K        | Cmd+K         |
| Computer MIDI Keyboard                                       | M            | M            |
| Adjust Computer MIDI Keyboard Octave Range Up/Down           | X and Z keys | X and Z keys |
| Adjust Computer MIDI Keyboard Incoming Note Velocity Up/Down | C and V keys | C and V keys |

Once the Computer MIDI Keyboard is turned on, these keys let you trigger notes and shift the octave and velocity ranges:

The Computer MIDI Keyboard Layout.

Even while the Computer MIDI Keyboard is running, single-letter shortcuts remain available if you prefix them with Shift — for instance, Shift+S to solo a track.

<a id="source-4125-momentary-latching-shortcuts"></a>
### 41.25 Momentary Latching Shortcuts

A number of shortcuts support momentary latching. In practice, this lets you press and hold the shortcut key to temporarily switch on its action; the moment you let go, Live’s interface snaps back to where it was. The latching behavior kicks in once you have held a shortcut key down for roughly 500 ms. These are the keys that allow momentary latching:

- A toggles Arrangement automation mode
- B toggles Draw Mode
- S toggles soloing the selected track
- Z toggles zooming into the Arrangement selection
- F1 through F8 flip the Track Activator switch for the first eight tracks between on and off
- Tab toggles between Arrangement and Session View

Should you want to disable it, momentary latching is switched off through the Options.txt entry: -DisableHotKeyLatching

<a id="source-4126-general-keyboard-navigation-and-workflow"></a>
### 41.26 General Keyboard Navigation and Workflow

The computer keyboard alone is enough to move through the majority of Live’s views, menus and controls.

Within Live’s menu bar, the Navigate menu gathers commands that shift keyboard focus across different parts of the UI, along with settings for moving between controls with Tab. You’ll find further navigation commands over in the Display & Input Settings.
