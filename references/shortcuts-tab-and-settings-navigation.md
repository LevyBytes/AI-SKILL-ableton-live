# Shortcuts Tab And Settings Navigation

Open when you need guidance on Shortcuts Tab And Settings Navigation in Ableton Live.

Context: [General Keyboard Navigation and Workflow](live-keyboard-shortcuts.md#4126-general-keyboard-navigation-and-workflow).

<a id="source-41261-using-tab-for-navigation"></a>
### 41.26.1 Using Tab for Navigation

With the Use Tab to Move Focus option turned on, the Tab key supports navigation in these ways:

- Tab moves to the next control
- Shift+Tab moves to the previous control

For moving among controls within the Session and Arrangement mixers, the Tab key works through these shortcuts as well:

- Ctrl+Tab (Win) / Option+Tab (Mac) advances to the next control sitting in that same row
- Ctrl+Shift+Tab (Win) / Option+Shift+Tab (Mac) steps back to the prior control sitting in that same row

With Use Tab to Move Focus disabled, a press of the Tab key flips between Session and Arrangement View, just as it did in earlier Live versions.

Beyond shifting focus with Tab, you also have access to these navigation options:

- _Wrap Tab Navigation_ - With this turned on, tabbing through a focused view won’t halt at its final control; instead it loops around to the first one. Likewise, when the first control is selected, Shift+Tab jumps to the last. You can switch this on from the Navigate menu or within the Display & Input Settings.
- _Move Clips with Arrow Keys_ - On by default, this lets the left and right arrow keys shift selected clips and/or the time selection inside Arrangement View. If you prefer, it can be turned off in the Display & Input Settings. Once off, the left arrow key snaps the time selection down to its start point, and the right arrow key snaps it down to its end point.

### 41.26.2 Navigating Between Controls in the Settings Menu

To step through the options held within the Settings tabs, use the Tab and Shift+Tab keys. They function here whether or not the Use Tab to Move Focus option happens to be active.

Whenever a command holds focus on one of the Settings tabs, the up and down arrow keys will flip a toggle’s state, tweak a value, or rotate through that command’s available choices. The Enter key can likewise be used to flip a toggle between its states.

Moving among the various tabs in the Settings Page Chooser is done with Ctrl+Tab (Win) / Option+Tab (Mac) and Ctrl+Shift+Tab (Win) / Option+Shift+Tab (Mac), or with the up and down arrow keys while the chooser has focus. Should keyboard focus rest on the first control of a Settings tab, pressing Shift+Tab hands focus back to the Settings Page Chooser.
